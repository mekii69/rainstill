Coins one new English word and defines it in a single line, written to `/output/entry.txt`:

> rainstill: the quiet, contented calm of being warm indoors with nowhere to go while rain falls outside.

The word names a feeling English has no single word for: the still, contented calm of being warm indoors, with nowhere to go, while rain falls outside. It is built from familiar English roots — *rain* + *still* — so it is sayable, spellable, and memorable at first sight.

## Run it

```sh
python3 main.py
```

Python 3 standard library only; no install step. The program writes exactly one line (103 characters) to `/output/entry.txt`, with no trailing newline.
